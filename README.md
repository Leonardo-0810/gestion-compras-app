
Esta aplicación es una sistema de gestion de compras desarrollado en laravel.

## Tecnologías
- Laravel 
- PHP
- Bootstrap
- MySQL

## Requisitos

- PHP 
- Composer
- Node.js y NPM
- MySQL

## Funcionalidad

- CRUD de productos
- CRUD de proveedores
- Generación de órdenes de compra
- Relación entre productos y proveedores
